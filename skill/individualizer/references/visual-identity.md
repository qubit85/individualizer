# Visual identity as a reusable system

Use when discovering or adapting visual style. Read actual reference images before claiming to match them.

## Translate taste into decisions

For each proposed direction, explain the intended impression and its concrete expression: palette roles, type hierarchy, whitespace, grid, shapes, illustration or photography treatment, and an optional signature motif. Show a small preview if tools permit. Label a textual art direction as a specification rather than a rendered preview.

Avoid adopting a source skill's house palette, typeface, or preferred art movement as the user's defaults. Check available fonts, glyph coverage for the target languages, and permitted assets.

## Record stable tokens and flexible rules

Define role-based colors, font families with fallbacks, spacing or grid relationships, hierarchy, icon/line treatment, image composition, and practical limits. Tokens without usage rules are insufficient: describe when an accent appears and what the motif communicates.

Separate exact constraints from flexible art direction. Repeatable chart geometry, brand colors, logo proportions, and labels may need vector or programmatic output. Generated illustrations can express a direction without guaranteeing exact repetition.

## Build for the actual content

Use the same identity differently in a dense report, a teaching diagram, and an expressive poster. Preserve chart labels, explanations, and accessible reading order. Minimal text is appropriate only when the artifact's purpose permits it.

Read factual input before deciding a chart. Do not invent data for visual impact. Check contrast against the applicable accessibility requirement with a suitable tool if available, plus readable sizes and non-color cues; do not assert compliance from palette appearance alone.

## Inspect a small family of outputs

Compare two or more relevant formats when validating an identity. Look for shared visual decisions without forcing identical layouts. Check exported artifacts for font substitutions, overflow, cropped text, missing glyphs, and altered color/data. Fix observed problems and record anything not inspectable.
