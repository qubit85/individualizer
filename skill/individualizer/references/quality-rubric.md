# Review the artifact, not an AI-detector score

For routine delivery, perform relevant checks quietly. For an audit, report pass, needs revision, not applicable, or unverified with concrete evidence. Do not average away a material error.

## Required gates

1. **Meaning:** source facts, negation, uncertainty, attribution, quantities, and commitments remain intact; no invented proof or personal experience. An unsupported addition fails the gate.
2. **Scope and protected content:** only authorized spans changed; exact quotes, code, links, identifiers, and structured data are intact unless their modification was requested.
3. **Voice and register:** the output fits the approved identity and current situation; formality, reader address, and regional conventions are consistent.
4. **Naturalness and structure:** each passage earns its place; no empty framing, forced pattern, or needless synonym cycling. Technical precision and expressive individuality survive.
5. **Medium and accessibility:** the actual text or rendered artifact is usable in its destination. Check the relevant media guide. Mark visual checks unverified if no rendering was inspected.
6. **Revision learning, when applicable:** earlier user corrections survive; active learned rules match this language/context; factual edits and one-off exceptions were not generalized. If a profile update was authorized, verify both saved files and preserve unrelated rules. Mark unavailable persistence unverified rather than claiming cross-chat memory.

A failure in meaning or protected content must be corrected before a style improvement is accepted. If a missing source or tool prevents resolution, state exactly what remains unverified.

## Evaluating a revision of this skill

Use fixed inputs with different voices and languages. Include English and German, a third language, technical text, meaningful contrasts, uncertainty, mixed-language passages, and edits that should leave a strong source almost unchanged.

Compare baseline and candidate on the same facts. Prefer blinded A/B reading by people familiar with the target language; alternate presentation order. Ask for naturalness, voice fidelity, clarity, and semantic errors separately. Keep input, output, selected profile, model/version if known, and reviewer observations. Never present expected answers, author self-review, or schema checks as independent behavioral validation.

Use results to improve specific instructions. Do not infer broad superiority from one impressive example.
